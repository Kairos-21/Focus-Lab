# 专注实验室 🧪

> 你刚坐下翻开书，手机亮了。
> "就看一眼消息"——等你放下手机，20 分钟过去了。
> 然后你打开 B 站查个教程，首页推荐把你带到了另一个宇宙。
> 天黑了。今天又过去了。
>
> **熟悉吗？**

欢迎来到**专注实验室**——一个不审判你、不给你打 F 级评分的拖延自救工具。

它的前身叫"拖延症模拟器"，但后来我们发现：**预演失败并不能让人停止失败**。于是我们改了个方向——不再让你看自己有多惨，而是每天花 2 分钟，像练肌肉一样练你的专注力。

## 这玩意儿怎么玩？

打开页面 → 选你今天的状态（精力如何？今天要干嘛？）→ 系统给你推一个适合的练习 → 花 2 分钟做完 → 看到自己在进步。

就三步。真的。

### 核心功能

| 功能 | 说明 |
|------|------|
| 📋 **每日签到** | 选精力和任务类型，系统智能推荐适合当下的练习 |
| 🧠 **微练习** | 8 个基于正经心理学研究的策略，每个只要 1-3 步 |
| 🔍 **探索模式** | 5 个日常拖延场景，看看你的"默认反应"是什么 |
| 📈 **成长看板** | 攒了多少次练习、连续几天、开了多少策略——**没评分没排名，纯记录** |
| 🎒 **策略库** | 所有策略一目了然，练过几次清清楚楚 |

## 8 个策略

都是正经心理学研究里扒出来的，但不用你读论文：

| 策略 | 难度 | 一句话 |
|------|------|--------|
| 📵 刺激控制 | 🌱 基础 | 把手机扔到另一个房间，比跟自己说"忍住"有用 100 倍 |
| ⏱ 10 分钟法则 | 🌱 基础 | 告诉自己"就做 10 分钟"——最难的是开始那一下 |
| 🍅 番茄工作法 | 🌱 基础 | 25 分钟干活 + 5 分钟摸鱼，循环，别想太复杂 |
| 🪴 环境设计 | 🌱 基础 | 让好习惯更容易、坏习惯更费劲，跟意志力没关系 |
| 🎧 诱惑捆绑 | 🌿 进阶 | 只有干活的时候才能听你最喜欢的播客 |
| 📝 待查清单 | 🌿 进阶 | 脑子里冒出的杂念写下来，告诉大脑"我记着了，你放心" |
| 🎯 执行意图 | 🔥 挑战 | "如果 X 发生，我就做 Y"——科学家说执行率能翻倍 |
| 💚 自我同情停顿 | 🔥 挑战 | 对自己说"这是人之常情"——真的比骂自己有用 |

## 怎么用？

项目是纯静态的，零依赖，下载就能用：

**💻 网页版（桌面端）** → 打开 `index.html`

**📱 移动端** → 打开 `mobile/index.html`
- 底部导航栏：今日 / 探索 / 成长
- 左右滑动手势切换
- 适配刘海屏
- 按钮够大，拇指友好

两边数据互通（共用一个 localStorage），今天在电脑上练，明天手机接着看进度。

## 技术

纯手工打造，没有框架，没有构建工具，没有 node_modules 这个黑洞：

- 单 HTML 文件架构（网页端 + 移动端各一个）
- CSS 和 JS 全部内嵌
- 零外部依赖，打开就能跑
- localStorage 持久化
