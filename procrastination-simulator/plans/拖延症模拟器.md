# 拖延症模拟器

## 产品概念
用户输入"我准备开始学习了"，AI 模拟人在学习前的一系列注意力崩塌过程，最后统计浪费的时间和本可以完成的事情。

## 技术方案
- 单页 HTML（index.html），CSS + JS 内嵌，零依赖
- 纯前端模拟，无需后端
- 响应式设计，移动端优先

## 模拟阶段（5 个递进 distract 场景）

| 阶段 | 触发语 | 模拟内容 |
|------|--------|----------|
| 1. 刷手机 | "刚坐下来，先歇会儿" | 解锁手机 → 刷朋友圈/小红书 → 15分钟过去 |
| 2. 打开B站 | "看个视频放松一下" | 首页推荐 → 点进一个 → 算法推荐下一个 → 无尽连播 |
| 3. 搜东西 | "突然想到一个问题" | 查资料 → 被带偏 → 打开10个tab → 忘了最初搜什么 |
| 4. 幻想人生 | "如果当初我..." | 开始做白日梦，幻想另一种人生 |
| 5. 放弃 | "算了明天再说" | 天黑了，收拾书包，带着愧疚结束一天 |

## 每个阶段结构
1. 状态栏：显示"计划：XXXX" vs "实际：XXXX"
2. 计时器：实时累加浪费的时间
3. 主画面：当前场景的视觉模拟（手机界面 / B站页面 / 浏览器tab / 发呆窗口）
4. AI 旁白：底部文字，冷嘲热讽或冷静记录

## 最终统计页
- 总浪费时间
- "你今天本来能完成的事情" 列表（动态生成，随浪费时间递增）
- 拖延等级评分（F - S）
- 重来按钮

## UI/UX
- 深色/浅色双主题，默认跟随系统
- 场景切换有过渡动画
- 计时器数字跳动效果
- 旁白文字打字机效果
- CSS 模拟的手机/B站/浏览器界面
