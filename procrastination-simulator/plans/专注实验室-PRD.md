# 专注实验室 — 产品需求文档

> 基于对"拖延症模拟器 V1-V4"的深度心理学分析后的产品重构方案
> 日期：2026-05-19

---

## 一、现有产品诊断

### 核心矛盾

原"拖延症模拟器"的底层范式是**失败模拟**——用户预演拖延过程，大脑在重复激活逃避的神经通路，适得其反。

### 七大心理设计缺陷

| # | 问题 | 心理学依据 | 表现 |
|---|------|-----------|------|
| 1 | 意识-行动鸿沟 | 知道 ≠ 做到（行为科学共识） | 用户懂了理论但没练出技能 |
| 2 | 自我效能感受挫 | Bandura 自我效能理论 | 每次选择预设"你会选错" |
| 3 | 回避-强化循环 | 负面情绪 → 逃避行为 | 内疚感反而强化拖延模式 |
| 4 | 意志力错误模型 | 近十年行为研究表明意志力更像情绪 | 用尽/恢复的简单模型误导用户 |
| 5 | 固定场景局限 | 个体差异极大 | 5 个场景无法覆盖真实多样性 |
| 6 | 缺乏纵向闭环 | 行为改变需要跨会话周期 | 一次性体验，无持续价值 |
| 7 | 审判式情感基调 | 自我决定理论 | 底层机制仍是"犯错误 → 被扣分" |

### PM 指标视角

- **次日留存**：接近 0（结果看一次就够了）
- **分享率**：低（没人分享 F 级截图）
- **行为转化**：未衡量
- **使用频率**：一次性

## 二、理论框架

| 理论 | 核心学者 | 产品应用 |
|------|---------|---------|
| **自我效能理论** | Bandura (1977) | 设计"微小胜利"循环，积累"我能做到"的信念 |
| **自我决定理论** | Deci & Ryan (2000) | 满足自主性/胜任感/归属感三大需求 |
| **执行意图** | Gollwitzer (1999) | If-then 计划使执行率翻倍 |
| **行为设计模型** | BJ Fogg (2009) | B=MAP，核心是降低能力门槛 |
| **习惯叠加** | James Clear (2018) | 新行为附着在已有习惯上 |
| **自我同情** | Kristin Neff (2003) | 自我关怀替代自我批评 |

### 四原则

1. **先练再说，不教而教**——让用户在行动中发现规律
2. **小到不可能失败**——启动门槛 < 10 秒
3. **数据为成长不为审判**——无评分无等级
4. **会话间有连续性**——跨会话积累

## 三、产品方案 — 「专注实验室」

### 定位转变

| 维度 | 原产品 | 新产品 |
|------|--------|--------|
| 名称 | 拖延症模拟器 | 专注实验室 |
| 定位 | 拖延模拟器 | 每日专注力训练工具 |
| 核心动作 | 做选择 → 看分数 | 做微练习 → 积累技能 |
| 使用频率 | 一次性 | 每日 2-5 分钟 |
| 情感基调 | 审判 → 改进 | 支持 → 成长 |
| 心理模型 | "你失败了" | "你在训练专注力肌肉" |

### 核心流程

```
每天打开 → ① 签到（精力 + 任务类型）
         → ② 做练习（1-3 分钟，基于推荐）
         → ③ 记录 + 反馈（30 秒）
         → ④ 看到累计进步
```

## 四、MVP 功能规格

### Screen 1: 每日签到（替代原 input 页）

- 品牌标题"专注实验室"
- 🔥 连续练习天数（localStorage）
- 精力选择：⚡充沛 / 👍正常 / 😴疲劳
- 今日类型：📚学习 / 💼工作 / 🎨创作 / 🏠日常
- 系统自动推荐适配练习
- 次入口："探索模式"（保留五关模拟）

### Screen 2: 练习（新增）

当前练习卡片，包含：
- 策略名称 + 难度 + 一句话说明
- 具体可执行的步骤（1-3 条）
- 完成按钮：[完成了] [做了一半] [今天先不了]
- 完成后给予鼓励反馈

### Screen 3: 成长记录（替代原 result 页）

- 今日练习总结
- 累计练习天数
- 已探索策略数
- 最近 7 天练习标记
- 可选"模拟模式"入口

### Screen 4: 模拟模式（原 game + result 改造）

- 保留 5 个场景和叙事，但：
- **移除 willpower 系统**
- **移除评分等级**
- 选择结果改为中性描述
- 结束后展示"注意力模式观察"而非分数

### Screen 5: 策略库（新增）

- 浏览所有策略（MVP 阶段 8 个）
- 标记已练习次数
- 按难度筛选

## 五、实施路线

### Phase 1 — MVP（本次实现）
- 单 HTML 文件，零依赖
- 每日签到 → 微练习 → 成长记录闭环
- localStorage 持久化
- 模拟模式改造（去评分、去意志力）

### Phase 2
- 扩展至 15-20 个策略
- 日历打卡视图
- 策略解锁机制

### Phase 3
- 基于历史数据个性化推荐
- 根据精力水平调整练习难度
- 用户自定义场景
