# 更新日志

## [1.0.0] - 2026-05-19

### 首个正式版 — 专注实验室

**网页版 + 移动端双平台**，每日专注力训练工具。

- **网页版**（桌面端）：签到 → 推荐练习 → 完成记录 & 探索 → 成长看板 + 策略库
- **移动端**（`mobile/index.html`）：底部三 tab 导航、滑动手势、触控优化、安全区域适配，同数据持久化
- **8 个心理学策略**：刺激控制、10 分钟法则、番茄工作法、环境设计、诱惑捆绑、待查清单、执行意图、自我同情停顿
- **5 个探索场景**：模拟日常拖延情境，观察注意力模式
- **无评分无等级**，所有数据为成长而非审判

## [0.5.3] - 2026-05-19

### 移动端独立版本

- **新增独立移动端页面**：在 `mobile/` 目录下创建单独的移动端 HTML 文件，与网页版共享同一套 localStorage 数据
- **底部标签导航**：今日（签到/练习）/ 探索（场景模拟）/ 成长（统计/策略库）三 tab 切换
- **滑动手势**：支持左右滑动切换标签页，跟随手指的 smooth 过渡动画
- **触控优化**：按钮统一 `:active` 缩放反馈、> 44px 触控区域、大字体输入框防止 iOS 自动缩放
- **安全区域适配**：`env(safe-area-inset-*)` 适配刘海屏和底部指示条
- **沉浸式主题**：深色背景 + 环境光晕，延续网页版视觉风格
- **完整功能闭环**：签到 → 推荐练习 → 完成记录 / 场景探索 → 注意力观察 / 成长看板 + 策略库

## [0.5.2] - 2026-05-19

### 网页版还原 + 移动端独立

- **网页版还原 v0.5.1 界面**：移除移动端适配 CSS，网页版保持桌面端形态
- **所有移动端优化移至独立版本**：安全区域、触摸手势、触控尺寸、横竖屏适配等全部归入 `mobile/` 独立页面

## [0.5.1] - 2026-05-19

### UI 视觉优化

- **环境氛围光**：每页增加径向渐变环境光 + 微差点阵纹理背景
- **连续天数环**：SVG 圆环可视化替代纯文字，天数颜色分三档
- **品牌头部增强**：图标发光外框、渐变分隔线、更大标题字号
- **签到选项升级**：选中态 ✓ 标记、渐变背景、上浮阴影；任务类型按色区分
- **卡片与微交互**：推荐卡片、练习步骤编号、庆祝动效、统计卡片 emoji、日历小圆点、场景彩色装饰条、选择卡片视觉区分、全局 transition

## [0.5.0] - 2026-05-19

### 产品重构 — 从「拖延症模拟器」到「专注实验室」

**核心理念转变**：从"失败的预演"转为"专注力的日常训练"。

- **品牌重塑**：更名为「专注实验室」，定位从一次性模拟工具转为每日专注力训练
- **每日微练习系统**：签到（精力+任务类型）→ 智能推荐练习 → 完成记录
- **8 个心理学策略**：含研究依据、具体步骤、难度分级
- **成长看板**：累计练习次数、连续天数、策略探索进度、最近 7 天日历（无评分无等级）
- **探索模式**：移除意志力系统和评分等级，选择改为"默认反应"vs"尝试策略"的中性框架
- **策略工具箱**：独立浏览所有策略，查看练习进度
- **localStorage 持久化**：跨会话保存
